# Argus-paper-reader 标注与深度分析规范指南 (Annotation Rubric)

> **品牌理念**：源自古希腊神话中的“百眼巨人”阿耳戈斯（Argus Panoptes，拥有百只眼睛，永不闭合）。在学术文献精读中，Argus 象征着**全视洞察论文的论证骨架、修辞策略与底层逻辑漏洞**。本规范定义了学术文献五维透镜高亮标准、高质量中文学术意译准则以及右栏三层批判性批注方法。

---

## 一、 Argus Five-Lens（五维高亮标注体系）

五维透镜旨在解构学术文本的深层论证网络。在英文正文中使用 HTML `<mark>` 标签包裹对应文本片段：
```html
<mark class="hl hl-{dim}" data-dim="{dim}" data-label="{label}">English Text</mark>
```

### 1. 维度定义与色彩语义

| 维度 ID (`data-dim`) | 颜色语义 | 视觉参数 (底色 / 边框 / 文字) | 识别对象与触发判定 |
| :--- | :--- | :--- | :--- |
| **`thesis`** (核心论点) | 琥珀金黄 | `#fef3c7` / `#d97706` / `#92400e` | 论文的核心假说、主要理论发现、中心因果主张、重大学术贡献。通常出现在引言末段、实证总结或结论首段。 |
| **`concept`** (关键概念) | 绯红/玫瑰 | `#ffe4e6` / `#e11d48` / `#9f1239` | 本文界定的专属理论范畴、新提出的学术术语、核心操作化变量定义、机制中的中介/调节构念。 |
| **`evidence`** (实证证据) | 湖水湛蓝 | `#e0f2fe` / `#0284c7` / `#075985` | 具体的量化结果、估计系数、统计显著性 ($p$ 值、置信区间)、描述性数据、关键比较事实或实证反驳证据。 |
| **`rebuttal`** (让步反驳) | 翡翠草绿 | `#dcfce7` / `#16a34a` / `#166534` | 作者主动提出的可能异议、前置让步、备选解释的排除、适用边界、外推局限与稳健性考量。 |
| **`method`** (方法论) | 罗兰紫罗 | `#f3e8ff` / `#9333ea` / `#6b21a8` | 识别策略（如双重差分 DID、工具变量 IV、断点回归 RDD）、计量模型设定、数据源与样本筛选规则、反事实构建逻辑。 |

### 2. 高亮标注实施准则
- **精准锚定**：仅高亮关键从句或谓词短语（通常 5~25 个词），严禁整段或多行连续高亮。
- **颗粒度分明**：一段内通常包含 1~3 处高亮，且各高亮维度的标签 (`data-label`) 需简明扼要（例如：`核心假说 H1`、`DID 基准估计`、`排除测量误差`）。
- **互斥性与纯粹性**：避免标签重叠嵌套。当句子兼具方法与论点时，依据该句在段落中的**主导功能**选择最契合的一维。

## 二、 中文学术意译准则 (Academic Paraphrasing Standards)

左栏下半部的中文翻译必须达到国内顶级学术期刊（如《经济研究》、《管理世界》、《中国社会科学》、《社会学研究》）的发表级水准：

1. **信达雅的学术重构**：
   - 彻底摒弃机器翻译常见的长定语从句直译与被动语态生硬堆砌（如严禁使用“它是被...所决定的”）。
   - 将英文的长链复合句重组为符合中文思维习惯的短句、主谓清晰的主动句或四字成语/学术成语（如“正本清源”、“互为因果”、“稳健可信”）。
2. **术语规范化与学术标点雅化**：
   - 严格采用学科公认的标准译名（如 *Identification Strategy* $\rightarrow$ **识别策略**；*Confounding Factors* $\rightarrow$ **混杂因素**；*External Validity* $\rightarrow$ **外在有效性 / 外推效度**；*Omitted Variable Bias* $\rightarrow$ **遗漏变量偏误**）。
   - **标点硬性规范**：中文译文与右栏批注中的专有名词、术语概念或重点强调，**统一使用直角引号 `「...」` 或标准中文双引号 `“...”`，严禁使用单引号 `‘...’` 或 `'...'`**。
3. **视觉纯净度**：
   - 中文译文块**不添加五维彩色高亮**，保持浅米底色的整洁排版，提供无干扰的高效阅读体验。

## 三、 右栏逐段三层批判性批注体系 (Three-Tier Critical Commentary)

每个 `.para-row` 右侧单元格必须呈现一张独立的结构化批注卡片，由浅入深解析该段的学术价值：

### ① 段落功能 (Paragraph Function)
- 使用胶囊徽章呈现段落的核心动作。
- 标椎词库包括但不限于：
  - `引出核心问题` / `梳理前沿脉络` / `构建理论假说`
  - `计量模型设定` / `样本与变量界定` / `识别策略论证`
  - `基准实证发现` / `机制与渠道检验` / `异质性分析`
  - `让步与异议排除` / `外生性冲击讨论` / `政策含义与总结`

### ② 逻辑角色 (Logical Role)
- 说明该段在全文逻辑骨架（Logic Chain）中的空间定位与承上启下作用。
- 模板范式：“承接上一段关于……的理论假设，本段通过……确立实证支柱，并为后文讨论……提供基准反事实参照。”

### ③ 论证解剖 (Argus Gaze)
从顶级期刊资深审稿人（Referee）的严苛视角进行双向解剖：
- **✦ 论证设计与修辞**：
  - 揭示作者高明的论述策略。例如：如何通过精巧的识别设计规避内生性争议？如何巧妙借用前人文献巩固先验前提？如何在引入实证前先建立直观经济学直觉？
- **⚑ 潜在漏洞与审稿质疑**：
  - 严厉审视实证或理论的致命弱点：
    - 是否存在未被观测到的时变混杂因素（Time-varying Confounders）？
    - 弱工具变量问题、排他性约束（Exclusion Restriction）是否仅凭直觉论证？
    - 样本选择性偏误（Selection Bias）与生存者偏差？
    - 机制检验中是否存在中介变量的内生性（Collider Bias）？
    - 外在有效性（External Validity）是否过于狭窄？

## 四、 底部全局复盘仪表盘规范 (Synthesis Dashboard Rubric)

论文末尾必须提供全局论证复盘仪表盘：

1. **全文逻辑骨架**：
   - 必须贯穿六大关键支柱节点：
     `问题 (Question) → 论点 (Thesis) → 方法 (Method) → 证据 (Evidence) → 反驳 (Rebuttal) → 结论 (Conclusion)`
   - 每个节点包含 1 句精炼概括。
2. **核心主张（Core Thesis）**：
   - 提炼论文最本质的因果发现或理论命题，字数在 50~100 字之间，严谨且具震撼力。
3. **核心方法论优势 vs. 阿喀琉斯之踵（识别软肋）**：
   - **核心方法论优势**：全篇最坚实的研究设计或最不可辩驳的实证事实。
   - **阿喀琉斯之踵（识别软肋）**：全篇最可能导致结论动摇、被审稿人拒稿或被后续文献证伪的根本短板。
